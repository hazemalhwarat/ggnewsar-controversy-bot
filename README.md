# GGNewsAR Players Bot

بوت يرصد **أخبار لاعبي الرياضات الإلكترونية** في كل الألعاب التنافسية ويرسلها إلى قناة Discord عبر Webhook. يعمل بالكامل على GitHub Actions بدون أي خادم وبدون أي خدمة ذكاء اصطناعي خارجية.

## ما الذي يرصده

- تصريحات اللاعبين
- المقابلات واللقاءات مع أي جهة
- ما تنقله المواقع عن حسابات اللاعبين في مواقع التواصل (تويتر/X، إنستقرام، تيك توك، تويتش)
- الانتقالات والعقود والاعتزال والعودة
- الأخبار الشخصية للاعبين (إصابة، صحة، تكريم، إيقاف... إلخ)
- أي خبر مرتبط بالأردن (قبول دائم حسب قاعدة الزاوية الأردنية)

يستبعد ضجيج المواعيد والنتائج والأدلة (schedule / results / patch notes / guides / skins) عندما لا يحمل الخبر أي إشارة تخص لاعباً.

## التشغيل

يعمل تلقائياً كل 15 دقيقة (`cron: */15`)، ويمكن تشغيله يدوياً من تبويب **Actions ← Check esports player news ← Run workflow**.

## الإعداد (خطوة واحدة)

أضف رابط الـ Webhook كـ Secret في الريبو:

`Settings ← Secrets and variables ← Actions ← New repository secret`

- الاسم: `DISCORD_WEBHOOK_URL`
- القيمة: رابط Webhook الخاص بقناة Discord

## الملفات

| الملف | الوظيفة |
|------|---------|
| `scripts/bot.mjs` | منطق البوت بالكامل (جلب، تصنيف، إرسال) |
| `.github/workflows/check-news.yml` | جدولة GitHub Actions |
| `data/seen.json` | ذاكرة الروابط المنشورة سابقاً (يُحدَّث تلقائياً) — لا يحوي أي سر |

## أهم الإعدادات (أعلى `scripts/bot.mjs`)

| المتغير | الافتراضي | الوظيفة |
|--------|:---------:|---------|
| `MAX_NEW_PER_RUN` | `50` | أقصى عدد مقالات تُعالَج في الدورة الواحدة |
| `MAX_ARTICLE_AGE_HOURS` | `36` | يتجاهل أي مقال أقدم من هذه المدة حسب تاريخ نشره الفعلي |
| `DEDUPE_LOOKBACK_DAYS` | `14` | مدة تذكّر الروابط لمنع التكرار |
| `INCLUDE_WHEN_NO_SIGNAL` | `false` | اجعلها `true` لإرسال **كل شيء** حتى بلا إشارة لاعب واضحة (ضجيج أعلى بكثير) |

## إضافة مصدر

أضف سطراً في مصفوفة `sources` داخل `scripts/bot.mjs`:

```js
{ name: 'اسم المصدر', url: 'https://example.com/feed' },
```

أي مصدر يفشل جلبه يُتجاوز تلقائياً دون التأثير على باقي المصادر.

## أول تشغيل

عند أول تشغيل بذاكرة فارغة (`data/seen.json` = `{}`)، يسجّل البوت المقالات الحالية كـ«مقروءة» **دون نشرها** لتفادي إغراق القناة بمحتوى قديم، ويبدأ النشر الفعلي من الدورة التالية (بعد 15 دقيقة).
